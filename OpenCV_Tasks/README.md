Multi-Object Color Tracker
This Python script is for tracking multiple objects in real-time using OpenCV. I built this project because a task asked me to find a reliable way to simultaneously track blue objects and tennis balls using a standard webcam, complete with lens distortion correction, unique color-coded trails, and live area calculations in both pixels and centimeters.

To get this running smoothly, you will first need a camera calibration file named camera_calibration.yaml placed in the same directory as the script. The code automatically loads this file to fix camera lens distortion and remap the frames on the fly, ensuring that my position measurements are as accurate as possible. It sets up a standard 640x480 video feed and applies HSV color thresholding along with morphological operations to clean up background noise and isolate the target objects.

It handles tracking and identification well. Instead of losing track of objects when they briefly overlap or vanish, it uses a custom tracking dictionary with a MAX_DISAPPEARED threshold and dynamic ID management. Every detected object gets its own randomly generated, unique color scheme—complete with persistent motion trails drawn onto a separate pitch-black canvas window. For tennis balls, I also baked in a non-maximum suppression (NMS) step to merge overlapping contour fragments and ignore tiny background specks.

With OpenCV and NumPy installed and camera calibration file into the folder, run the script. Once the live windows pop up, one can watch the tracker identify individual objects, calculate their sizes, and even draw a connecting distance vector when both a blue object and a tennis ball are in view. Whenever one is done, just press the 'q' key to cleanly release the webcam and close all windows.

Building this tracker wasn't entirely smooth sailing, and I definitely ran into a few frustrating hurdles along the way that took some trial and error to sort out. My first major headache was lens distortion warping my camera's field of view, which threw off position tracking and made trying to calculate real-world sizes and relative distances pretty unreliable. To fix that, I integrated a dedicated camera calibration pipeline that loads up a custom YAML file and remaps every single frame on the fly, ensuring that my pixel coordinates stay true and accurate regardless of where things move in the frame.

Another massive challenge came up when I started tracking tennis balls specifically. Because of their fuzzy texture, yellow-green color, and uneven lighting shadows, they kept breaking apart into messy internal fragments or triggering a bunch of tiny, annoying false-positive contours all over the screen. I ended up solving this by beefing up the morphological closing operations and writing a custom non-maximum suppression routine. By sorting the raw circle detections by their radius and merging any overlapping duplicates that sat too close together, the script finally learned to treat a tennis ball as a single, solid object instead of a chaotic cluster of specks.

Finally, keeping track of multiple objects simultaneously without them constantly losing their identity or swapping IDs when they crossed paths took a lot of fine-tuning. Eventually, it took time but I perfected it upto my satisfaction.
